# OBJ model presets

The first three presets are unmodified copies of existing assets in this Falcor checkout. All presets use
the sample's existing OBJ loader (positions and faces); UVs, MTLs and OBJ normals
are not imported. Centering/scaling changes positions at runtime only. Open mesh
boundaries are preserved.

GraphEx Heart (7,656 vertices / 15,308 triangles) and GraphEx Tangle Cube
(17,800 / 35,616) are offline polygonal exports of GraphEx's `heart.slang`
and `implicit_TangleCube.slang` equations under
`Shaders/Example/Lipschitz/Samplers/Procedures/Implicits/`.
[export_graphex.py](../../analysis/gpu/orientation/export_graphex.py) samples a
40³ grid with marching tetrahedra and checks closure. This does not add an SDF
importer or ray tracer. Historical measurements used byte-identical copies
under `analysis/gpu/orientation/models/`.

The ten `ResearchCandidates/*.obj` assets (five sources and five controls) are
generated by [generate.py](../../analysis/gpu/five_candidates/generate.py).
Their descriptions, source hashes and counts are in
[models.json](../../analysis/gpu/five_candidates/models.json). Each control has
the same vertex list and triangle count; panel controls balance planar fans,
knot control removes UV shear, and ramp control only shortens cell diagonals.
Sources deliberately include poor connectivity; these are research fixtures.

GraphEx's existing license is retained in [GraphEx-LICENSE.txt](GraphEx-LICENSE.txt);
Falcor's distribution notice is retained in [Falcor-LICENSE.md](Falcor-LICENSE.md).
These copies preserve the upstream notices; they do not relicense upstream assets.

CMake deploys this folder to `bin/Release/Data/HelperLaneWindows/Models`.
`--self-test` checks each deployed asset through OBJ import and Source Faces,
including triangle counts and the existing topology audit.
